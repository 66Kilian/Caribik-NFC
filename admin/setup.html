MK Admin beállítása

1. Jelszó

Legalább 12 karakter. Minden a böngésződben készül, semmi nem megy el sehova.

2. Kétlépcsős azonosítás

Olvasd be a QR-kódot egy hitelesítő alkalmazással (Google Authenticator, Microsoft Authenticator, 1Password, Authy …), majd írd be a 6 jegyű kódot.

Kézi megadáshoz a titkos kulcs:

Tipp: mentsd el ezt a kulcsot a jelszókezelődbe is. Ha elveszik a telefonod, ezzel tudod visszaállítani.

3. Beállítás a Vercelben

Vercel → a projekted → Settings → Environment Variables. Add hozzá az alábbi értékeket (Environment: Production), majd indíts egy Redeploy-t.

Plusz a mentéshez szükséges GitHub-token (lásd ADMIN.md):

GITHUB_TOKENFine-grained token → Repository access: csak meinekontaktkarte → Permissions: Contents: Read and write
GITHUB_BRANCHAz a branch, amiből az éles oldal települ (általában main)

Ezt az oldalt zárd be, ha kész vagy. Az értékeket ne küldd el senkinek.
